# STM32 PCB Design

This repository contains my STM32-based PCB design project, developed while following the [STM32 PCB Design Tutorial Series](https://www.youtube.com/playlist?list=PL3aaAq2OJU5HcbClqrOhqBDozF7HmxV-s).

The project is still in progress and serves as a practical way to improve my PCB design skills using Altium Designer.

## Interactive PCB Viewer

The schematic and interactive 3D PCB view are available through GitHub Pages:

🔗 **[View Schematic & 3D PCB](https://skillygonzales.github.io/STM32-Tutorial/)**

The interactive viewer allows you to explore the PCB layout, inspect components, and visualize the board in 3D directly in your browser.

## What I've Learned

For this project, I designed a **4-layer PCB** using Altium Designer, learning and applying concepts such as:

**Schematic Design**
- Organizing schematics into multiple hierarchical sheets
- Creating a top-level overview schematic
- Annotating components to easily identify their corresponding schematic sheets

**PCB Layout**
- Defining the PCB stackup and layer buildup
- Routing differential pairs and configuring controlled impedance
- Improving component placement and routing efficiency
- Using solid ground and power planes
- Maintaining ground plane continuity and avoiding unnecessary splits
- Defining PCB cutout regions
- Adding ground stitching vias
